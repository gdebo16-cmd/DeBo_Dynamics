# DeBo Dynamics

Personal portfolio site for Gabriel DeBoer. Company-style landing page with a home view, theme toggle, and project sections.

**GitHub Pages:** https://gdebo16-cmd.github.io/DeBo_Dynamics/

## Stack

HTML, CSS, vanilla JavaScript

## Run locally

Open `project/home/home.html` in a browser, or serve the repo root with any static server so relative asset paths resolve.

```bash
npx serve .
```

Then visit `/project/home/home.html`.

## Layout

- `project/home` — landing page and light/dark theme toggle
- `project/auth` — login UI mock (front-end only, no real accounts)
- `project/Assets` — images

The root `index.html` sends visitors to the home page.
